# WorkBuddy Switch Next 0.2.7-rc.202611101657

本候选版补上 TRAE 国内版每日签到，并把 Qoder 每日领取更新到公开上游。支持 Windows x64 与 macOS Apple Silicon（arm64）。

## 本版变化

- TRAE 国内版账号页可以领取每日签到积分。按钮位置与 WorkBuddy、Qoder 相同，排在「刷新积分」后面。
- 签到使用已保存的登录和客户端注册过的设备号，不生成假设备号。同一官方设备每天只能签一个账号；人数过多时不连发。
- Qoder Daily 同步到 L0NE-6/Qoder-Daily v1.0.19。10:00（UTC+8）前不再请求上一轮奖励，已领取的活动不再当成失败。
- WorkBuddy Daily 仍为 v3.41，上游没有更新的提交。

## 安装与升级

- 本版使用 preview 更新入口；正式版的 latest 通道不接收 RC。正式版用户体验本版需手动下载安装包。
- 沿用 ~/.wb-switch 数据目录。安装包包含管理 CLI 和每日任务组件。
- 下载文件可使用同页 SHA256SUMS 校验。

## 验证与边界

发布前已通过 Rust 格式检查、版本通道检查，以及 TRAE 签到状态和设备号单测。国际版 TRAE 签到尚未接入。真实签到是否到账以上游回执为准。
