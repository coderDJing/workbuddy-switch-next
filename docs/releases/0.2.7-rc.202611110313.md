# WorkBuddy Switch Next 0.2.7-rc.202611110313

本候选版修正 macOS 版首次打开提示「已损坏」的问题，并调整应用图标外观。支持 Windows x64 与 macOS Apple Silicon（arm64）。

## 本版变化

- 修复 macOS 版安装后提示「已损坏，无法打开」：此前打包没有给 .app 做代码签名，应用包缺少 `_CodeSignature`，系统校验直接判为损坏。现在按 Tauri 的 ad-hoc 方式对应用包签名，安装后可以正常打开（首次仍需在「隐私与安全性」中允许一次，因为未做 Apple 公证）。
- macOS 应用图标不再显示为米白色方块：图标按系统栅格（1024 画布、824 内容区、185.4 圆角）烘焙为四角透明，Dock 与 Finder 中与其它应用一致。
- 打包流程新增两道校验：应用包签名必须有效，且 DMG 里的副本必须保留签名，任一环节出问题构建直接失败，不再把坏包发出去。
- 构建遇到 GitHub macOS runner 无可用容量时自动重试，不再需要人工重跑。

## 安装与升级

- 本版使用 preview 更新入口；正式版的 latest 通道不接收 RC。正式版用户体验本版需手动下载安装包。
- 沿用 ~/.wb-switch 数据目录。安装包包含管理 CLI 和每日任务组件。
- macOS 上仍然不是 Apple 公证的应用，首次打开若提示「无法验证开发者」，在「系统设置 → 隐私与安全性」里选择「仍要打开」即可；旧版提示「已损坏」时执行 `sudo xattr -rd com.apple.quarantine "/Applications/WorkBuddy Switch Next.app"`。
- macOS 安装后如 Dock 仍显示旧图标，执行 `killall Dock` 刷新图标缓存。
- 下载文件可使用同页 SHA256SUMS 校验。

## 验证与边界

发布前已通过发布身份检查与产物收集测试，并在构建中校验应用包与 DMG 内的代码签名。应用仍未做 Apple 公证。
