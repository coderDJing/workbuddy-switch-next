# WorkBuddy Switch Next 0.2.5

本正式版与候选版 0.2.5-rc.202611101348 使用同一套代码，去掉 RC 后缀并切换到正式版更新通道。0.2.4 因为 Rust 格式检查未通过而没有发布 Release。支持 Windows x64 与 macOS Apple Silicon（arm64）。

## 本版变化

- 按 rustfmt 整理 TRAE 额度解析和对应测试，使发布检查可以通过。
- 功能与未发布的 0.2.4 相同：TRAE 国内版读取官方 v2 额度并按积分包展示到期时间，Qoder 使用同一套积分包卡片。额外积分没有官方到期时间时仍显示未提供。

## 安装与升级

- 正式版使用 latest 更新入口，不接收 RC。已安装 RC 的用户请退出应用后手动安装本正式版。
- 沿用 ~/.wb-switch 数据目录。桌面安装包附带同版本 CLI，安装后请新开终端。
- 正式版关闭普通 RC 诊断日志，正常错误日志保留既有行为。
- 可使用同页 SHA256SUMS 核对安装包完整性。

## 验证与边界

发布前已通过 `cargo fmt --check` 和版本通道检查。安装包与远端构建结果以本版 GitHub Actions 和 Release 实际产物为准。
