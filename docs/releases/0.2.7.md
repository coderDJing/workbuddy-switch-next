# WorkBuddy Switch Next 0.2.7

本正式版汇总 0.2.7 RC 周期的更新，支持 Windows x64 与 macOS Apple Silicon（arm64）。

## 本版变化

- 新增 MiniMax Code：账号识别、设备码登录、加密保存、切换核验、积分查询与领取、Token 和积分统计、自动任务及独立 WebDAV 同步。
- 新增豆包平台：账号识别与加密保存、切换核验与恢复、官方额度窗口、每日签到、自动任务、统计、密码备份及独立 WebDAV 对象。
- 对齐五个平台的账号卡片、响应式布局和疏密偏好，MiniMax、豆包支持排序与宽松布局。
- 修复 TRAE 积分查询与账号更新并发时的状态提示，保留国内版每日签到及 Qoder Daily 更新。
- 改进 MiniMax 状态查询性能、当前账号识别和 CLI 超时处理，补齐界面空值保护与使用说明。

## 安装与升级

- 正式版使用 latest 更新入口，不接收 RC；已安装 RC 的用户请退出应用后手动安装本正式版。
- 沿用 `~/.wb-switch` 数据目录。桌面安装包包含同版本 CLI 和每日任务组件。
- 正式版关闭普通 RC 诊断日志，正常错误日志保留既有行为。
- 下载文件可使用同页 SHA256SUMS 校验。

## 验证与边界

两个支持平台的构建、测试及发布产物校验均已通过。MiniMax 国际版、豆包首次发奖与不同账号切换、真实 WebDAV 同步尚需对应环境验收；MiniMax Token 统计不能按账号或区域归因，豆包没有可靠 Token 数据来源。macOS 应用尚未做 Apple 公证。
