# WorkBuddy Switch Next 0.2.2

本正式版改善 AI CLI 的一键复制体验，方便把完整工具说明交给人或 AI 编写 Skill。对应候选版 `0.2.2-rc.202611062058` 已完成 Windows、Linux、macOS Intel / Apple Silicon 构建，全部 CI 测试与更新清单验证通过。

## 本版变化

- AI CLI 顶部新增「复制 Skill 接入说明」，一次复制当前客户端与区域、能力发现、命令示例、参数、JSON 返回、退出码、数据边界及操作约定。
- 新增「复制全部查询命令」，保留单条命令复制；批量查询文本不混入切号或领取操作。
- 内容随 CodeBuddy CLI、Qoder CLI、Qoder 桌面端及所选区域变化，区分支持的命令和参数，不包含实际账号、凭据或本机私有路径。
- 提供完整说明预览与手动全选复制；剪贴板不可用时自动展开预览，切换目标或区域后正确更新复制提示。
- README、CLI 文档和界面截图同步更新。

复制和预览只生成文本，不执行命令，也不创建或安装 Skill。说明包含当前构建版本，实际安装版本与能力仍以 CLI 返回为准。

## 安装与升级

- 正式版从 `latest` 接收更新，RC 保留在 `preview`，两通道隔离。已安装 RC 的用户请退出应用后手动安装本正式版。
- 继续使用原有 `~/.wb-switch` 数据目录，无需删除账号库。桌面安装包附带同版本 CLI，安装后请新开终端。
- 可使用同页 `SHA256SUMS` 核对安装包完整性。Qoder 模型限额、统计数据覆盖和每日任务等已知限制沿用 0.2.1；本版本不改变这些能力边界。
