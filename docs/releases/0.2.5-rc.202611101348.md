# WorkBuddy Switch Next 0.2.5-rc.202611101348

本候选版与 0.2.4 的功能相同，只修正 Rust 格式检查。0.2.4 的 Windows 与 macOS 安装包已经构建成功，但格式检查未通过，Release 没有发布。支持 Windows x64 与 macOS Apple Silicon（arm64）。

## 本版变化

- 按 rustfmt 整理 TRAE 额度解析和对应测试，使发布检查可以通过。
- 功能与 0.2.4 相同：TRAE 国内版读取官方 v2 额度并按积分包展示到期时间，Qoder 使用同一套积分包卡片。额外积分没有官方到期时间时仍显示未提供。

## 安装与升级

- 本版使用 preview 更新入口；正式版的 latest 通道不接收 RC。
- 沿用 ~/.wb-switch 数据目录。安装包包含管理 CLI 和每日任务组件。
- 下载文件可使用同页 SHA256SUMS 校验。

## 验证与边界

发布前已通过 `cargo fmt --check` 和版本通道检查。0.2.4 的前端测试失败是 npm 镜像超时，不是测试断言失败。macOS 与国际版客户端尚未完成本机人工验收。
