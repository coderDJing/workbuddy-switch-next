# WorkBuddy Switch Next 0.2.2-rc.202611062058

本 RC 改善 AI CLI 的批量复制体验，方便直接把工具说明交给人或 AI 编写 Skill。

- AI CLI 顶部新增「复制 Skill 接入说明」，一次复制当前客户端与区域、能力发现、命令示例、参数、JSON 返回字段、退出码、数据边界及操作约定。
- 新增「复制全部查询命令」，保留各条命令的独立复制；复制查询命令不会混入切号或领取操作。
- 接入说明随 CodeBuddy CLI、Qoder CLI、Qoder 桌面端及所选区域变化，区分各目标支持的命令与参数，不包含实际账号、凭据或本机私有路径。
- 可预览完整说明并手动全选复制；剪贴板不可用时自动展开预览。切换客户端或区域后，复制成功提示随内容更新。
- README、CLI 文档与界面截图同步更新。

复制和预览仅生成文本，不执行命令，也不创建或安装 Skill。说明中的来源版本随构建同步，实际安装版本与能力以 CLI 返回为准。

本地已验证前端构建、127 项前端测试、三个目标的复制内容、区域切换、剪贴板失败回退和小窗口布局。本 RC 使用 `preview` 更新通道，与正式版隔离。
