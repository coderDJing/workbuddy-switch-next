# WorkBuddy Switch Next 0.2.1

本正式版汇总 0.2.1 RC 阶段的改进，完善 Qoder 统计、自动任务、AI CLI 与 Next 工作台。最终候选版 `0.2.1-rc.202611061914` 的 Windows、Linux、macOS Intel / Apple Silicon 构建和 CI 验证均已通过。

## Qoder 用量与自动化

- 新增本地 Token 和积分统计，支持趋势、模型筛选与请求明细。缺失或全零占位 Token 显示不可用，不按积分反推 Token。
- 独立记录账号额度快照与观察消耗，同一身份的桌面端和 CLI 去重；本地请求积分与额度快照分开展示，不相加为账单。
- 国内版、国际版分别设置每日领取、低余额和到期提醒、CLI 空闲轮换。自动功能默认关闭，仅在桌面应用或 webui 服务运行时执行。
- 支持 Qoder CLI Hooks 接入会话悬浮窗，以及复用全局连接的独立 WebDAV 加密备份、预览恢复和合并同步。

## 面向 AI 的 CLI

- 新增 `qoder-cli`、`qoder-desktop` 目标，支持账号、状态、切换、积分与汇总查询，以及 `token-stats`、`credit-stats`、`rewards`、`automation`。
- 沿用统一 JSON 输出、稳定账号 ID、区域筛选、逐账号错误及部分成功退出码；`help --json` 提供能力清单。
- Qoder 切换默认不关闭运行中的客户端，需显式 `--close-running`；桌面端另加 `--relaunch` 才重开原本运行的客户端。
- 侧栏新增 AI CLI 调用指南，可选择客户端与区域并复制查询命令，打开指南不会执行命令。

## 账号备份、每日任务与界面

- 设置中可把 WorkBuddy、CodeBuddy 和 Qoder 账号导出到同一 JSON 文件，导入前预览账号数量。导入跳过已有账号并补充缺少的 Qoder 客户端；导出按身份与客户端去重，保留较新的账号包。
- 账号页分开提供「刷新积分」与「领取积分」：刷新只查询余额，领取执行对应每日任务并更新余额。桌面安装包附带每日任务组件。
- 导航按工作空间、用量洞察、自动化与配置分组，优化深浅主题及小窗口布局。Qoder 设置页明确显示待保存状态，保存后再检查任务。
- README 突出 Next 的多平台、统计与自动化特点，并补充工作台、Qoder 设置和 AI CLI 截图。

## 安装与升级

- 从本 Release 下载对应平台安装包或独立 CLI，可使用同页 `SHA256SUMS` 核对完整性。
- 升级前正常退出旧版，继续使用 `~/.wb-switch` 账号库，无需删除数据。安装后请新开终端；macOS / Linux AppImage 需先启动应用完成 CLI 注册。
- 正式版使用 `latest` 更新入口，RC 继续使用 `preview`，两通道互不自动迁移。已安装 RC 的用户请手动安装本正式版，之后接收正式版更新。
- 独立 CLI 执行每日任务时，还需同平台 `daily-runner`（Windows 为 `daily-runner.exe`），放在 CLI 同目录。
- 正式版不写 RC 诊断日志。应用更新及启动失败后的下载入口均指向正式版通道。

## 验证与已知限制

- Qoder 国内版真实额度查询、已有登录文件的 Windows 桌面切换及隔离 CLI 切换已验证。国际版、macOS / Linux 的真实客户端操作、全新桌面目录首次启动、自动续期及跨客户端同时使用仍需实际环境验证；CI 构建与测试通过不等于这些场景已验收。
- Qoder 模型限额和恢复时间缺少可靠来源，明确返回未知或不支持；本地会话历史不按账号隔离。
- 每日奖励和自动任务的资格、执行效果及到账以上游结果为准。部分任务可能创建对话、消耗积分或能量；请求成功不代表奖励到账。
- 导出备份包含登录凭据，应妥善保管。部分 WorkBuddy 加密凭据绑定原设备，跨设备恢复后可能需要重新登录。
