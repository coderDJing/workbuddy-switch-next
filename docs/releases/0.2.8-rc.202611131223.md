# WorkBuddy Switch Next 0.2.8-rc.202611131223

- 新增「今日领取详情」弹窗：账号卡片上的领取标记、以及账号页工具栏的列表按钮都能打开，逐账号列出「已完成 / 可领 / 未达标」计数、未完成的任务名与各自状态、原因、核对时间和触发来源；今天还没跑过的账号也会列出来，不再只有悬停才能瞄一眼的 tooltip。
- 领取完成的提示简化为数量：「3 个账号已领完，2 个还有任务未完成」；任务名、警告和错误原文不再塞进提示，改由提示里的「查看详情」按钮直达弹窗。MiniMax、TRAE、Qoder、豆包同步。
- 提示分级按新口径走：全部可领项都领完显示成功；还有任务或失败显示警告；全部跳过或未开放显示中性提示；全部失败才显示错误。
- 补齐每日任务返回值的类型声明（`total` / `claimed` / `claimable` / `blocked`），前端不再靠 `remaining.length` 推断。
- 新增 6 项前端测试覆盖弹窗正文（任务名、未达标标记、未跑账号、空态）与状态文案。

此版本通过 preview 通道发布。
