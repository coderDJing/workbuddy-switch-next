# WorkBuddy Switch Next 0.2.3-rc.202611090934

本候选版更新每日任务组件，支持 Windows x64 与 macOS Apple Silicon（arm64）。

## 本版变化

- WorkBuddy Daily 同步至 v3.41：通过任务阶段快照减少重复查询，识别签到积分延迟到账，并修复旅行领奖、盲盒与派出的执行顺序。
- 收紧账号限制识别，减少模型限流与正文示例导致的误判；请求渠道被拒绝（11-128）时明确提示并停止本轮任务。
- 保留桌面登录与会话保护，任务执行不替换桌面账号、不删除会话，令牌续期继续由主程序负责。
- macOS 构建与测试使用原生 Apple Silicon runner；同步构建矩阵、npm 平台包、安装文档和发布校验，并保留旧 Windows 更新地址的兼容入口。
- Qoder Daily 沿用当前上游提交，本轮无新增更新。

## 安装与升级

- RC 通过 `preview` 接收候选版更新，与正式版 `latest` 通道隔离。
- 继续使用原有 `~/.wb-switch` 数据目录，无需迁移账号库。桌面安装包附带同版本 CLI，安装后请新开终端。
- 可使用同页 `SHA256SUMS` 核对安装包完整性。

每日任务回归使用模拟请求与隔离状态目录；本轮未使用真实账号执行任务。安装包、签名及远端测试结果以对应 GitHub Actions 和 Release 实际产物为准。
