# WorkBuddy Switch Next 0.2.0

首个社区维护正式版，基于 WorkBuddy Switch v0.1.62，汇总 Next 预览及 RC 阶段的改进，维护桌面 GUI、webui 与一次性 CLI。

## 本版变化

- 使用 Next 名称、蓝色 N 贝雷帽图标、独立应用标识与更新签名，沿用原有账号库。
- 增加独立 Qoder 平台，支持国内版 / 国际版桌面端与 CLI 的网页登录添加、本机账号识别、账号切换、备份导入导出和积分查询。账号按身份合并，卡片区分套餐、额外与专属积分，接口提供有效日期时显示到期时间。
- 桌面安装包内置同版本 `workbuddy-switch-next` CLI；补齐 Windows PATH、macOS / Linux 用户命令注册与 Linux deb 命令安装，并保留 Release 独立 CLI 下载。
- 一次性 CLI 支持账号、积分、到期和模型限额概览及 CodeBuddy CLI 切换；GUI 与 CLI 共用认证锁，改善外部状态同步和凭据刷新保护。
- 支持按账号统计 Token / 调用量、最近使用记录与多维排序；限额台账定时刷新，自动签到使用分散窗口。
- 改善跨账号会话复制、置顶同步、创建时间保留与陈旧会话归档保护；关联会话支持副本查看、增量同步及分歧处理。
- 提供 WebDAV 加密备份、选择恢复与双向同步，包含凭据新旧判断、ETag 并发保护及恢复预览校验。
- 扩充 JetBrains 系列与 Android Studio 支持，改善 Windows 客户端关闭、重开与认证写入保护，以及 Agent Companion 的会话状态和跳转行为。
- 区分平台设置与全局设置，优化滚动条、macOS 标题栏和 Qoder 多客户端账号卡片；修复账号状态循环造成的内存持续增长。

上游 PR 来源、贡献者与详细维护记录见 [维护说明](https://github.com/coderDJing/workbuddy-switch-next/blob/main/docs/FORK-MAINTENANCE.md)。感谢原作者与社区贡献者，保留原项目版权及 MIT 许可。

## 安装与升级

- 从本 Release 下载 Windows x64、macOS Apple Silicon / Intel、Linux x64 安装包，或对应独立 CLI；使用同页的 `SHA256SUMS` 核对文件完整性。
- 升级前正常退出旧版。Next 继续使用 `~/.wb-switch`，无需删除账号库；macOS 可能需要按新应用名称重新授予 App 管理或完全磁盘访问权限。
- 正式版从 `latest` 获取正式版更新，RC 从 `preview` 获取 RC 更新，两通道隔离。已安装 RC 的用户需手动安装本正式版；后续留在正式版通道。
- 安装后请新开终端使用 CLI；macOS / Linux AppImage 需先启动桌面应用完成命令注册。命令冲突与 PATH 排查见 [CLI 文档](https://github.com/coderDJing/workbuddy-switch-next/blob/main/docs/cli.md)。

## 已知限制与验证范围

- Qoder 已完成 Windows 国内版网页登录添加、已有登录文件的桌面切换与恢复，以及隔离目录下的官方 CLI 登录身份确认。全新桌面目录首次启动、国际版、macOS / Linux、自动续期及跨客户端同时使用尚未完成真实验证。
- Qoder 账号不参与 WebDAV 同步，会话历史不按账号隔离。一次性 CLI 切号只支持 CodeBuddy CLI；Qoder 等其他客户端使用 GUI / webui。
- CodeBuddy CLI 切换会关闭运行中的 CLI，不会自动重开。webui 不提供桌面专属的 Agent Companion 悬浮窗。
- 自动化账号、认证、会话和 WebDAV 测试使用合成数据或隔离目录，不能替代所有真实客户端与服务的验证。本版本三平台测试、四平台构建与发布结果以关联的 GitHub Actions 为准。
- 更新包使用 Next updater 签名；该签名不等同于 Windows 开发者代码签名或 Apple 公证。
