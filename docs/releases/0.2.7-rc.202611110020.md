# WorkBuddy Switch Next 0.2.7-rc.202611110020

本候选版修正 macOS 应用图标外观与首次安装说明。支持 Windows x64 与 macOS Apple Silicon（arm64）。

## 本版变化

- macOS 应用图标不再显示为米白色方块：图标按系统栅格（1024 画布、824 内容区、185.4 圆角）烘焙为四角透明，Dock 与 Finder 中与其它应用一致。
- macOS 首次打开说明改为可直接执行的三种方式：清理隔离属性、命令行下载安装（不产生隔离属性）、签名被破坏时重新 ad-hoc 签名。发布页面也会自动带上这段提示。
- 打包流程在生成 DMG 后校验镜像内应用的代码签名，签名在复制过程中被破坏时构建直接失败，不再把坏包发出去。

## 安装与升级

- 本版使用 preview 更新入口；正式版的 latest 通道不接收 RC。正式版用户体验本版需手动下载安装包。
- 沿用 ~/.wb-switch 数据目录。安装包包含管理 CLI 和每日任务组件。
- macOS 安装后如 Dock 仍显示旧图标，执行 `killall Dock` 刷新图标缓存。
- 下载文件可使用同页 SHA256SUMS 校验。

## 验证与边界

发布前已通过发布身份检查与产物收集测试。应用仍未做 Apple 公证，首次打开需要按上方说明清理隔离属性。
