# WorkBuddy Switch Next 0.2.8-rc.202611131031

- 新增「今日领取记忆」：账号页与各平台的「领取积分 / 领取奖励」按钮会记住今天的领取结果，已领完时显示「今日已领完」，不再让用户反复触发几分钟一轮的每日任务。
- 判定以「还有没有可领的」为准：进度达标但尚未领奖的任务计入剩余项；锁定、未达标、需要客户端操作的任务不再让按钮永远停在「未领完」。企业版、账号受限、活动未开放单独归为「今日无可领取」，结果未知（超时/回执丢失）标记待确认且不重复提交。
- 账号卡片新增任务标记，与「今日已签到」分开显示：签到成功不等于成长任务都领完了，这是此前误以为已领完的主要来源。悬停可看到「已完成 / 可领 / 未达标」计数与未完成任务名。
- 已领完时按钮仍可点，但会先弹一次确认；在官方客户端或另一台设备领过后，可在设置页「今日领取记录」清除后重新核对。
- 覆盖五个入口：WorkBuddy / CodeBuddy 账号页、MiniMax、TRAE、Qoder、豆包；单账号菜单项在已领完时同步置灰并改文案。豆包后台自动周期的结果也写入同一份记忆。
- 每日任务组件补充「可领 / 未达标」计数与任务中文名；Qoder 领奖返回结构化状态，不再只能靠文案判断。
- 记忆按北京时间切日，保留 30 天汇总与 7 天任务明细，只记录账号 ID、任务名与状态，不保存凭据、昵称或原始响应。

此前三次 RC 尝试（`202611122341`、`202611130947`、`202611131005`）均因 macOS 构建环境问题未能产出安装包：先是托管 runner 分配不到，随后是 sidecar 复制目标被占用导致 EPERM / EISDIR。本版本把 companion sidecar 的打包名改为 `agent-runtime`，避开与 cargo 产物同路径的冲突，并让 `tauri-build` 的清理动作失败不再中断构建；应用功能与此前一致。

此版本通过 preview 通道发布。
