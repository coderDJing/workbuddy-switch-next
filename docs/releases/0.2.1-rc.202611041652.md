# WorkBuddy Switch Next 0.2.1-rc.202611041652

修复全部账号备份遇到同一 Qoder 账号的重复客户端账号包时无法导出的问题。导出时按账号身份和客户端合并，优先使用较新的账号包，同时保留桌面端和 CLI 凭据。

- 设置中可将 WorkBuddy、CodeBuddy 和 Qoder 账号导出到同一个 JSON 文件；导入时跳过已有账号并补充缺少的 Qoder 客户端账号。
- 备份包含登录凭据，请妥善保管。部分 WorkBuddy 加密凭据绑定原设备，跨设备恢复后可能需要重新登录。
- 账号页支持刷新和领取积分，领取会运行对应的每日任务。任务可能需要较长时间，也可能创建对话或消耗积分和能量；结果以上游为准。
- 本 RC 使用 preview 更新入口，与正式版更新通道隔离。单独下载 CLI 时，还需下载同平台的每日任务组件并放在同一目录，改名为 `daily-runner`（Windows 为 `daily-runner.exe`）。

每日任务尚未用真实账号执行验证；活动是否开放、桌面回退是否计数和积分是否到账以上游实际结果为准。
