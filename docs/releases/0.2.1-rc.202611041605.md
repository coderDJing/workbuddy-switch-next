# WorkBuddy Switch Next 0.2.1-rc.202611041605

本 RC 在设置中新增全部账号备份，可将 WorkBuddy、CodeBuddy 和 Qoder 账号导出到同一个 JSON 文件，并在导入前查看账号数量。导入会跳过已有账号、保留本机凭据，Qoder 会补充缺少的客户端账号。备份包含登录凭据，请妥善保管；部分 WorkBuddy 加密凭据绑定原设备，跨设备恢复后可能需要重新登录。

- 账号页分别提供刷新积分和领取积分；领取会运行对应的每日任务。任务可能需要较长时间，也可能创建对话或消耗积分和能量；实际结果以上游为准。
- Qoder 国内版和国际版可检查并领取可用积分活动；国际版需要 UMID 设备身份，令牌失效时需要重新登录。
- 优化发布构建流程：测试和平台构建并行，发布仍需全部验证通过。
- 本 RC 使用 preview 更新入口，与正式版更新通道隔离。单独下载 CLI 时，还需下载同平台的每日任务组件并放在同一目录，改名为 `daily-runner`（Windows 为 `daily-runner.exe`）。

每日任务尚未用真实账号执行验证；活动是否开放、桌面回退是否计数和积分是否到账以上游实际结果为准。
