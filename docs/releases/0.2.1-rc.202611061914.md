# WorkBuddy Switch Next 0.2.1-rc.202611061914

本 RC 完善 Qoder 的统计、自动任务与 AI CLI，并更新 Next 工作台导航、设置页和使用文档。

## Qoder 用量与自动化

- 新增本地 Token 和积分统计：支持趋势、模型筛选与请求明细；缺失或全零占位 Token 显示不可用，不从积分推算 Token。
- 独立记录账号额度快照与观察消耗，同一身份的桌面端和 CLI 去重；本地请求积分与额度快照分开展示，不相加为账单。
- 国内版、国际版独立设置每日领取、低余额和到期提醒、CLI 空闲轮换；自动任务默认关闭，仅在桌面应用或 webui 服务运行时执行。
- 支持 Qoder CLI Hooks 接入会话悬浮窗，以及复用全局连接的独立 WebDAV 加密备份、预览恢复和合并同步。

## 面向 AI 的 CLI

- 新增 `qoder-cli`、`qoder-desktop` 目标，支持账号、状态、切换、积分和汇总查询，以及 `token-stats`、`credit-stats`、`rewards`、`automation`。
- 沿用 JSON 信封、稳定账号 ID、区域筛选、逐账号错误与部分成功退出码；`help --json` 提供能力清单。
- Qoder 切换默认拒绝关闭运行中的客户端，需显式 `--close-running`；桌面端另加 `--relaunch` 才重开原本运行的客户端。
- 模型限额与恢复时间没有可靠数据源，Qoder 明确返回未知或不支持。

## Next 工作台

- 导航按工作空间、用量洞察、自动化与配置分组，强化 Next 标识，优化深浅主题和小窗口布局。
- Qoder 设置页分组展示自动任务、连接与备份、执行记录；编辑后提示待保存，保存后再检查任务。
- 侧栏新增 AI CLI 调用指南，可按客户端和区域复制查询命令；打开指南不会执行命令。
- README 围绕多平台、用量与自动化重新组织，并补充新版界面截图。

## 验证与兼容范围

已完成本机前端构建与测试、CLI 协议与隔离切换测试；两个真实国内版账号的额度查询成功。浏览器验证覆盖深浅主题、小窗口、区域切换及命令复制。

Qoder 国际版、macOS / Linux、全新桌面目录首次启动、自动续期及跨客户端同时使用仍需实际环境验证。每日奖励和自动任务的资格、执行效果及最终到账以上游结果为准；不会把请求成功当成到账证明。

本 RC 使用 `preview` 更新入口，与正式版通道隔离。桌面安装包附带同版本 CLI 和每日任务组件；独立 CLI 执行每日任务时，还需同平台的 `daily-runner`（Windows 为 `daily-runner.exe`）。账号切换和备份继续使用现有数据目录，无需删除账号库。
