# WorkBuddy Switch Next 0.2.7-rc.202611101801

本候选版去掉 TRAE 账号卡片上会一直留下的「账号正在更新」。支持 Windows x64 与 macOS Apple Silicon（arm64）。

## 本版变化

- 判断 TRAE 是否在运行时不再占着账号锁。刷新积分和读取状态可以同时进行。
- 积分查询如果正好遇到账号库正在写入，会先等待再重试一次，不再把「TRAE 账号正在更新，请稍后重试」留在卡片上。
- 已经查到的积分余额保持不变。上一版的国内版每日签到和 Qoder Daily v1.0.19 仍然包含在内。

## 安装与升级

- 本版使用 preview 更新入口；正式版的 latest 通道不接收 RC。正式版用户体验本版需手动下载安装包。
- 沿用 ~/.wb-switch 数据目录。安装包包含管理 CLI 和每日任务组件。
- 下载文件可使用同页 SHA256SUMS 校验。

## 验证与边界

发布前已通过 Rust 格式检查和版本通道检查。国际版 TRAE 签到尚未接入。
