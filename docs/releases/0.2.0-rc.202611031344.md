# WorkBuddy Switch Next 0.2.0-rc.202611031344

本次 RC 完善 Qoder 账号管理、备份迁移和客户端图标。

- Qoder 国内版和国际版支持在本工具中登录添加账号，桌面端和 CLI 分别选择切换；Windows 上可自动识别并保存本机已登录的账号。
- 同一账号的客户端登录按已验证的身份合并，账号卡片展示积分余额，并支持排序和刷新。用户删除的账号不会被后台自动重新添加。
- 支持将 Qoder 账号导出为 JSON 备份并在另一台电脑导入。备份包含登录凭据，请妥善保管；导入不会自动切换客户端。
- Qoder 账号页面的布局与 WorkBuddy 对齐，整理侧边栏标题，调整托盘图标和 CLI 图标，使客户端类型更易区分。

已在 Windows 上验证国内版真实授权、已有桌面客户端的账号切换及原账号恢复，并在隔离目录验证 CLI 识别、备份和自动识别。国际版、macOS / Linux 和另一台实体电脑尚未实测；macOS / Linux 桌面端可能需要系统钥匙串授权，首次初始化及跨客户端凭据续期仍需进一步验证。登录凭据过期时可能需要重新登录。

修复 Qoder 切换代码在 macOS / Linux 严格检查下的告警；Windows CLI 进程扫描的等待时限与预览保持一致；相关测试增加等待时间并串行执行，缓解高负载环境下的间歇性失败。

本版使用 preview 更新入口，与正式版隔离。
