# WorkBuddy Switch Next 0.2.6-rc.202611101404

本候选版让 macOS 发布检查在检测到 Qoder CLI 进程时不再把隔离测试判失败。0.2.5 的正式版构建因此没有进入发布步骤。支持 Windows x64 与 macOS Apple Silicon（arm64）。

## 本版变化

- Qoder CLI 端到端测试在目标进程确实在运行时保持现场文件不变并跳过，覆盖切换内部返回的“正在运行”错误。
- 其余功能与 0.2.5 相同。

## 安装与升级

- 本版使用 preview 更新入口；正式版的 latest 通道不接收 RC。
- 沿用 ~/.wb-switch 数据目录。安装包包含管理 CLI 和每日任务组件。

## 验证与边界

0.2.5 的 macOS 测试失败点是 `qoder_cli_switch_uses_its_own_lock_backup_and_credentials`：干跑认为空闲，实际切换又发现 Qoder CN CLI 进程，错误码是 `SWITCH_FAILED` 而不是测试原先接受的 `CLIENT_RUNNING`。本版按“正在运行”处理。安装包结果以本版 GitHub Actions 为准。
