# WorkBuddy Switch Next 0.2.3

本正式版补齐现有平台的 CLI 业务管理，并更新 WorkBuddy 每日任务组件。支持 Windows x64 与 macOS Apple Silicon（arm64）。对应候选版 0.2.3-rc.202611091112 已完成两个支持平台的构建、签名、完整 CI 检查及 Release 发布；本次基于相同功能代码移除 RC 后缀，切换到正式版更新通道。

## 本版变化

- CLI 覆盖 WorkBuddy、CodeBuddy IDE、CodeBuddy CLI、VS Code / JetBrains CodeBuddy 插件和 Qoder 桌面端 / CLI，提供状态、账号、积分、综合查询与切号。
- WorkBuddy/CodeBuddy 增加平台 Token / 积分统计和按账号每日签到；login 命令在同一进程等待官方授权，成功后保存账号，不切换客户端。
- operations / call 与 WebUI 共用操作和参数契约，补齐账号导入导出、会话复制/关联/同步、自动任务配置、限额 Hooks、Qoder CLI Hooks 与 WebDAV；输入契约纳入 CI 校验。
- 桌面切号默认拒绝关闭运行中的客户端，需要时显式使用 --close-running --relaunch；命名切号校验客户端区域并要求明确的进程参数。
- 普通结果隐藏凭据，导出要求显式输出文件且不覆盖已有文件；失败与部分成功使用非零退出码，保留会话预览令牌。
- 界面中的 AI CLI 指南覆盖七种目标，说明区域、平台统计及命令边界。
- WorkBuddy Daily 更新至 v3.41，改善签到延迟到账、任务快照与旅行/盲盒执行顺序，并收紧限制识别；Qoder Daily 沿用当前上游版本。
- 构建与平台测试限定 Windows x64 和 macOS Apple Silicon。

## 安装与升级

- 正式版使用 latest 更新入口，不接收 RC；RC 保留 preview 入口，不自动转正式版。已安装 RC 的用户请退出应用后手动安装本正式版。
- 沿用 ~/.wb-switch 数据目录，无需删除或迁移账号库。桌面安装包附带同版本 CLI，安装后请新开终端；macOS 首次启动应用完成命令注册。
- 正式版关闭普通 RC 诊断日志，正常错误日志保留既有行为。
- 可使用同页 SHA256SUMS 核对安装包完整性。

## 验证与边界

候选版已通过 Windows / macOS Apple Silicon 的核心、CLI、桌面及 Companion 测试、前端检查、严格 Clippy、安装包内置组件和签名/更新清单验证。Windows 本地核心单测 926 项通过、5 项跳过，CLI/server 77 项、桌面端 33 项和前端 129 项通过，并通过隔离账号、认证并发及 WebDAV 集成测试。

上述验证不代表真实账号切号、登录、领取或真实 WebDAV 已完成验收。桌面悬浮窗窗口、原生权限窗口、开机自启及桌面更新重启仍由桌面宿主管理；模型限额和统计数据缺失保持未知。正式版安装包与远端构建结果以本版 GitHub Actions 和 Release 实际产物为准。
