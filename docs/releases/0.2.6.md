# WorkBuddy Switch Next 0.2.6

本正式版与候选版 0.2.6-rc.202611101404 使用同一套代码，去掉 RC 后缀并切换到正式版更新通道。0.2.5 的 macOS 测试在检测到 Qoder CLI 进程后失败，Release 没有发布。支持 Windows x64 与 macOS Apple Silicon（arm64）。

## 本版变化

- Qoder CLI 端到端测试在目标进程确实在运行时保持现场文件不变并跳过，覆盖切换内部返回的“正在运行”错误。
- 其余功能与 0.2.5 相同。

## 安装与升级

- 正式版使用 latest 更新入口，不接收 RC。已安装 RC 的用户请退出应用后手动安装本正式版。
- 沿用 ~/.wb-switch 数据目录。桌面安装包附带同版本 CLI，安装后请新开终端。
- 正式版关闭普通 RC 诊断日志，正常错误日志保留既有行为。

## 验证与边界

安装包与远端构建结果以本版 GitHub Actions 和 Release 实际产物为准。
