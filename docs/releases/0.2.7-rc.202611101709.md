# WorkBuddy Switch Next 0.2.7-rc.202611101709

本候选版修正 TRAE 自动签到的结果判定，并补上设置页。支持 Windows x64 与 macOS Apple Silicon（arm64）。

## 本版变化

- TRAE 国内版可以在平台设置里打开自动领取每日积分，并设置本机时区的领取时间。到点后自动签到，错过则启动补领；每天最多 3 次，失败间隔 30 分钟。
- 自动任务按签到回执的成功标记记账。签到成功或今日已签到记为成功，不会因为回执里没有失败状态字段而被当成失败。人数过多时只排队，不发失败提醒。
- 账号页的「领取积分」仍排在「刷新积分」后面，样式与 WorkBuddy、Qoder 相同。
- 命令行增加 TRAE rewards，可领取国内版每日签到积分。
- Qoder Daily 仍为公开上游 v1.0.19。

## 安装与升级

- 本版使用 preview 更新入口；正式版的 latest 通道不接收 RC。正式版用户体验本版需手动下载安装包。
- 沿用 ~/.wb-switch 数据目录。安装包包含管理 CLI 和每日任务组件。
- 下载文件可使用同页 SHA256SUMS 校验。

## 验证与边界

发布前已通过 Rust 格式检查、服务端编译、版本通道检查，以及 TRAE 自动任务单测。国际版 TRAE 签到尚未接入。同一官方设备每天只能签一个账号。真实签到是否到账以上游回执为准。
