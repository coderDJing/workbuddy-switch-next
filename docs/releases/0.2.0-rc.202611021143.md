# WorkBuddy Switch Next 0.2.0-rc.202611021143

本次 RC 将命令行工具集成进桌面安装包。

- Windows 安装包内置同版本 CLI，并为当前用户注册 workbuddy-switch-next 命令；卸载时只移除本安装器添加的 PATH 条目。
- macOS 和 Linux AppImage 首次启动应用时创建用户级命令入口；Linux deb 直接安装命令。安装后请新开终端；已有同名命令不会被覆盖。
- 命令可以查询账号积分和已观察到的模型限额，例如 workbuddy-switch-next limits --text。未观察到限额不代表模型一定可用。
- Windows 安装流程使用程序原生注册表操作，不调用 PowerShell 来修改 PATH。发布流程检查各平台桌面包是否包含 CLI。

本地 Windows 包已验证包含 CLI，注册表隔离测试通过。本地临时测试安装器曾被 Defender 拦截；重新打包的测试安装包本机扫描没有新增告警，但完整安装、macOS 和 Linux 仍需实机验证。

继续支持 Qoder 国内版与国际版。真实双账号往返切换仍需实测。本版通过 preview 更新入口发布，与正式版隔离。
