# WorkBuddy Switch Next 0.2.0-rc.202611021158

本次 RC 将命令行工具集成进桌面安装包，并调整 Qoder 账号页面。

- Windows 安装包内置同版本 CLI，并为当前用户注册 workbuddy-switch-next 命令；卸载时只移除本安装器添加的 PATH 条目。安装器使用原生注册表操作，不调用 PowerShell 修改 PATH。
- macOS 和 Linux AppImage 首次启动应用时创建用户级命令入口；Linux deb 直接安装命令。安装后请新开终端；已有同名命令不会被覆盖。
- Qoder 账号页按国内版和国际版切换，各版本单独显示账号、客户端状态和认领入口，并支持与 WorkBuddy 一致的紧凑／宽松卡片布局。
- 修复桌面 CLI 安装测试并行运行时临时目录冲突，避免 macOS 发布门禁失败。

本地 Windows 包已验证包含 CLI，注册表隔离测试通过。此前临时测试安装器曾被 Defender 拦截；重新打包的测试安装包本机扫描没有新增告警，但完整安装、macOS 和 Linux 仍需实机验证。Qoder 真实双账号往返切换仍需实测。

本版通过 preview 更新入口发布，与正式版隔离。
