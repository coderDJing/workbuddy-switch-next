# WorkBuddy Switch Next 0.2.4-rc.202611091738

本候选版接入 TRAE 桌面端中国版与国际版，统一三平台的使用体验。支持 Windows x64 与 macOS Apple Silicon（arm64）。

## 本版变化

- 修复 macOS 并发启动子进程时账号事务结束后文件锁可能短暂残留的问题，避免连续 TRAE 操作误报“账号正在更新”；增加句柄继承场景的锁释放回归测试。

- TRAE 使用官方图标，并对齐 WorkBuddy、Qoder 的账号卡片、区域切换、排序、重命名和切号交互。
- 支持读取与保存本机账号、查询额度及安全切号；切号检查客户端进程、区域和登录有效期，保留原有项目与会话数据。
- 增加可用的 TRAE 额度统计，按账号、区域、时间和计量单位查看采样记录；无数据时保持未知，不展示不可用的 Token 统计。
- 增加 TRAE 自动刷新、额度与登录提醒、符合条件时自动切号，以及独立的中国版和国际版配置。自动化默认关闭。
- 支持 TRAE 密码加密备份、预览后导入及独立 WebDAV 备份文件；导入保留已有账号。
- 设置中可以分别隐藏 WorkBuddy、Qoder 和 TRAE，隐藏不删除账号；允许全部隐藏后直接进入设置。
- 管理 CLI 增加 trae-desktop 目标及对应账号、额度、统计和自动化操作。此次不接入原生企业 TRAE CLI，不保留旧版独立 SOLO。

## 安装与升级

- 本版使用 preview 更新入口；正式版的 latest 通道不接收 RC。正式版用户体验本版需手动下载安装包。
- 安装包包含管理 CLI 和每日任务组件；安装后新开终端使用命令，macOS 首次启动应用完成命令注册。
- 沿用 ~/.wb-switch 数据目录。TRAE 账号使用独立存储，本机凭据通过 Windows DPAPI 或 macOS 钥匙串保护。
- 下载文件可使用同页 SHA256SUMS 校验。发布流水线成功后提供两个支持平台的安装包。

## 验证与边界

发布前已通过前端 134 项行为测试、类型检查与构建，Windows 核心 946 项单元测试和 21 项集成测试（另有 6 项需真实环境的测试默认跳过）、CLI/server 80 项测试、桌面端 33 项测试，以及 Rust 格式和严格 Clippy 检查。发布脚本、CLI 启动器、版本与更新清单检查通过。TRAE 回归覆盖协议、账号隔离、安全切号、加密备份、统计和自动化，并已在本机中国版客户端验证只读认证与额度查询。

macOS、国际版客户端及真实 WebDAV 写入尚未完成本机人工验收；两平台构建结果以本版 GitHub Actions 为准。额度统计来自实际采样，不推算缺失的 Token 或历史消耗。
