# WorkBuddy Switch Next 0.2.8-rc.202611131601

- 每日任务组件升级到上游 WorkBuddy v3.48、Qoder v1.0.22。WorkBuddy 侧新增 `skill_share` 自动完成、小程序与星巴克 `app` 任务自动执行、签到重试持久化；Qoder 侧修复国际版 claim 风控头，并改为「额度回读增加才算成功」。
- 四份集成补丁全部重新套用：导入不加载账号、补领判定抽到模块级、守护进程会话目录按凭据文件选择、摘要给出 `claimed` / `claimable` / `blocked`。
- Qoder 的「已受理但额度待确认」不再记成失败：适配层新增 `unconfirmed`，不重试、不谎报成功。
- 豆包签到加固：活动组改为从 `/alice/user/launch` 动态获取（官方换组名不再 404），按组选择 `campaign/v3/detail` 或 `campaign/list`，回执额外校验 `data.biz_error.code`，提交后按 0 / 1.5 / 3 秒回查三次再判定，避免把「已经领到」记成待确认。
- sidecar 构建补上 `websocket-client`：它是上游 v3.48 的新依赖，函数内导入，漏装只会在新账号走 CDP 兜底发送时失败。
- 新增 `docs/UPSTREAMS.md` 与 `docs/upstreams.json`：五个平台的上游（脚本快照与协议参考）、固定 commit、许可与跟进流程；`npm run upstreams:check` 比对漂移，每周一由 `Upstream drift` 自动跑一次（它标红表示上游有更新，不是构建失败）。

此版本通过 preview 通道发布。
