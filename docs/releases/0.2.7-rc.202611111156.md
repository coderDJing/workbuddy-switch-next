# WorkBuddy Switch Next 0.2.7-rc.202611111156

本候选版新增 **MiniMax Code** 平台接入：账号识别、加密账号包、整组切换、积分查询、工具内设备码登录，以及专用管理 CLI。同时修掉了一批状态读取与界面健壮性问题。支持 Windows x64 与 macOS Apple Silicon（arm64）。

## 本版变化

### MiniMax Code 接入

- 平台栏新增 MiniMax Code（只有「账号管理」一页），账号库与其它平台隔离。桌面端与 CLI 共用同一份登录态，因此按区域分国内版 / 国际版，只有一个切换目标。
- **添加账号两种方式**：在工具内完成 OAuth 设备码授权（弹窗显示用户码并自动打开浏览器，无需先打开客户端、不切换客户端当前登录），或识别官方客户端已有的登录。登录密钥只留在进程内，不落盘、不进日志。
- **切换**：先请求客户端正常退出，再成组写入 `auth.json` 与 `auth-state.json`，把两份文件的 `generation` 同步抬高、清掉刷新事务，写完读回核验，失败恢复原文件；按需重新打开客户端。客户端拒绝退出时直接停止，不强制终止进程。
- **积分**：查询官方积分明细与套餐信息。非现场账号用 refresh token 换新并回写账号包；现场账号只读不刷（代刷会让客户端自己的会话失效）。
- **身份补全**：授权响应通常不带 `sub`，登录成功后按官方客户端的签名规则问一次用户资料接口，补上真实 uid、昵称和邮箱；同一账号的重复卡片自动合并。早期版本留下的「账号 N」占位卡片可在菜单里点「识别身份」事后补齐。
- **专用 CLI**：`--target minimax-desktop` 支持 `accounts` / `status` / `inspect` / `credits` / `switch` / `login`，`--variant cn|ai` 选区域；不支持的命令明确返回 `UNSUPPORTED_CAPABILITY`，不伪造数据。

### 稳定性与界面

- `status` 读取提速约 5 倍：现场凭据每区域只解析一次，进程探测只做一次并改为按映像名过滤的 `tasklist`。实测从 1.6–2.4 秒降到 0.3–0.8 秒。查询失败仍返回错误，不会在客户端还开着时误判成「没运行」。
- 修复「当前账号」判定：重新登录过的同一账号不再同时显示「本机当前登录：尚未添加」和一张同名卡片。写入仍以代际为准，点切换能真正把新令牌同步进客户端。
- 补齐前端空值兜底：SPA 回退返回 `{}` 时，多处 `x?.field.find(...)` 会崩，统一改为 `(x?.field ?? [])`，覆盖平台栏、设置、TRAE / Qoder 积分统计与会话弹窗。
- 客户端现场令牌过期时，MiniMax 页面会给出提示，说明本工具不代刷、打开一次客户端即可自行刷新。
- CLI 的 `--timeout` 现在真正生效；`login` 在轮询开始前就输出用户码和授权地址，不必等到超时才知道该输什么。

## 安装与升级

- 本版使用 preview 更新入口；正式版的 latest 通道不接收 RC。正式版用户体验本版需手动下载安装包。
- 沿用 `~/.wb-switch` 数据目录。MiniMax 账号包在 `~/.wb-switch/minimax/accounts.json`，明文令牌不落盘；安装包包含管理 CLI 和每日任务组件。
- macOS 上仍不是 Apple 公证的应用，首次打开若提示「无法验证开发者」，在「系统设置 → 隐私与安全性」里选择「仍要打开」即可；旧版提示「已损坏」时执行 `sudo xattr -rd com.apple.quarantine "/Applications/WorkBuddy Switch Next.app"`。
- 下载文件可使用同页 SHA256SUMS 校验。

## 验证与边界

- 本机（Windows，MiniMax Code 3.1.13 国内版）实测：识别本机登录、工具内设备码授权完整通过、登录当场解析身份并并入已有账号卡、加密保存、真实切换写入（代际 1→2、两文件一致）、专用 CLI 各命令、积分查询与超时/取消路径。
- 离线测试覆盖 32 项 MiniMax 用例（含代际、回滚、进程拒绝、重复卡合并、签名与 MD5 向量）与 14 项 CLI 用例；前端 134 项测试、类型检查与构建均通过。
- **尚未实测**：MiniMax 国际版（`en`）的真实登录与 macOS 分支。国际版域名与签名逻辑按官方客户端同构实现，界面与代码路径一致。
- MiniMax 没有 Token 统计、会话复制、自动轮换与悬浮窗接入：其本地用量数据格式尚未核实。
