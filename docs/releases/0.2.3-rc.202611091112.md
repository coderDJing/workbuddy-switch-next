# WorkBuddy Switch Next 0.2.3-rc.202611091112

本候选版补齐现有平台的 CLI 业务管理，支持 Windows x64 与 macOS Apple Silicon（arm64）。

## 本版变化

- WorkBuddy、CodeBuddy IDE、VS Code 和 JetBrains CodeBuddy 插件新增 CLI 目标，提供状态、账号列表、积分、综合查询与切号；保留 CodeBuddy CLI 和 Qoder 原有命令兼容。
- WorkBuddy/CodeBuddy 补充平台 Token 与积分统计、按账号每日签到；新增同进程等待官方授权的 login 命令，授权成功只保存账号。
- 新增 operations / call：通过与 WebUI 共用的操作和参数契约，调用账号导入导出、会话复制/关联/同步、自动任务配置、限额 Hooks、Qoder CLI Hooks 和 WebDAV。参数契约加入 CI 校验。
- 桌面切号默认拒绝关闭运行中的客户端；显式使用 --close-running --relaunch 才允许重启。只读预览不验证凭据。命名切号同样需要明确的进程参数。
- 普通命令输出隐藏令牌和密码，凭据导出要求显式输出文件且不覆盖已有文件；失败与部分成功使用非零退出码，保留会话预览令牌。
- AI CLI 指南覆盖全部七种目标，补充参数、区域与平台统计边界。
- 包含上一候选版的 WorkBuddy Daily v3.41 更新和 Apple Silicon 构建矩阵调整。

## 安装与升级

- RC 通过 preview 接收候选版更新，与正式版 latest 通道隔离。
- 沿用 ~/.wb-switch 数据目录，无需迁移账号库。桌面安装包附带同版本 CLI，安装后请新开终端。
- 桌面悬浮窗窗口管理、原生权限窗口、开机自启及桌面更新重启仍由桌面宿主管理。
- 可使用同页 SHA256SUMS 核对安装包完整性。

Windows 本地检查：核心单测 926 项通过、5 项按原规则跳过，账号/认证/并发/WebDAV 集成测试通过；CLI/server 77 项、桌面端 33 项、前端 129 项测试通过。类型检查、前端生产构建、严格 Clippy、格式检查、命令注册、版本一致性、操作契约及发布辅助测试通过。

本地验证使用 Windows 与隔离测试数据，不使用真实账号切号、登录、领取或连接真实 WebDAV。macOS 与真实客户端操作尚未进行本机验收；安装包、签名和远端测试结果以对应 GitHub Actions 与 Release 实际产物为准。
