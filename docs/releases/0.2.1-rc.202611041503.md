# WorkBuddy Switch Next 0.2.1-rc.202611041503

本 RC 在账号页分别提供「刷新积分」和「领取积分」按钮。刷新只查询余额；领取会执行对应的每日任务，并在完成后更新余额。领取进行时仍可手动刷新。

- WorkBuddy 国内版领取包括成长、小程序、互动和补领任务；国际版包括每日活跃与可用奖励。签到遵守签到时间段，其他任务可在窗口外运行；设置中可按账号排除。
- Qoder 国内版和国际版领取会检查可领取的积分活动及 Pro 升级包。国际版需要 UMID 设备身份；领取待确认、账号受限或凭据失效时会显示实际状态。
- 桌面安装包与 CLI 平台包包含每日任务组件。任务可能需要较长时间，也可能创建对话或消耗积分和能量；桌面任务优先使用当前登录账号的会话，其余使用网络回退。
- 本版本使用 preview 更新入口，与正式版更新通道隔离。单独下载 CLI 时，需要同时下载并将同平台的每日任务组件放在同目录，改名为 `daily-runner`（Windows 为 `daily-runner.exe`）。

每日任务尚未用真实账号执行验证；活动是否开放、桌面回退是否计数和积分是否到账以上游实际结果为准。Qoder 登录令牌失效时需要重新登录。
