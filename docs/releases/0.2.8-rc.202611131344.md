# WorkBuddy Switch Next 0.2.8-rc.202611131344

- 领取入口改成「先看再领」：点「领取积分 / 领取奖励」不再直接跑几分钟的任务，而是打开今日领取详情，逐账号列出已完成 / 可领 / 未达标计数、未完成的任务名与各自状态、原因、核对时间和触发来源。
- 弹窗底部的「领取全部」才是真正的执行入口（今天已领完时显示「重新核对」），旁边写明这次会影响几个账号、大概要多久；执行中按钮显示进度，跑完面板数据自动刷新。
- 取消原来「已领完 → 是否重新核对」的二次确认弹窗：打开的面板本身就是确认步骤，不用连点两层。
- 卡片上的领取标记、账号页工具栏的列表按钮仍然是直接看详情的入口；弹窗里今天还没跑过的账号也会列出，避免「没显示＝没问题」。
- 完成后的提示只报数量（如「3 个账号已领完，2 个还有任务未完成」），并带「查看详情」按钮回到面板；任务名、警告与错误原文不再出现在提示里。MiniMax、TRAE、Qoder、豆包同步。
- 状态口径不变：可领项为 0 即视为今日已领完，锁定任务不会再让按钮停在「未领完」。

此版本通过 preview 通道发布。
