# WorkBuddy Switch Next 0.2.4

本正式版修正 TRAE 国内版积分读取，并把 TRAE、Qoder 的积分展示对齐 WorkBuddy 的积分包卡片。支持 Windows x64 与 macOS Apple Silicon（arm64）。对应候选版 0.2.4-rc.202611101153 使用同一套功能代码；本次去掉 RC 后缀，切换到正式版更新通道。

## 本版变化

- TRAE 国内版改为请求官方 v2 额度接口。菜单余额计入仍有剩余的积分包，缺省已用按 0 计算，不再把可识别余额显示成额度未知。
- TRAE 账号卡片按到期时间展示积分包名称、剩余和进度；超过两包可查看全部。已过期、隐藏和加速包不计入。
- Qoder 账号卡片改为同一套积分包排版。套餐积分和专属积分显示官方到期时间；额外积分没有单独到期字段时显示未提供。
- 桌面发布只上传安装包、自动更新包、签名、更新清单和校验和。CLI 与每日任务组件留在安装包内，不再单独发布命令行包。

## 安装与升级

- 正式版使用 latest 更新入口，不接收 RC；RC 保留 preview 入口，不自动转正式版。已安装 RC 的用户请退出应用后手动安装本正式版。
- 沿用 ~/.wb-switch 数据目录，无需删除或迁移账号库。桌面安装包附带同版本 CLI，安装后请新开终端；macOS 首次启动应用完成命令注册。
- 正式版关闭普通 RC 诊断日志，正常错误日志保留既有行为。
- 可使用同页 SHA256SUMS 核对安装包完整性。

## 验证与边界

发布前在 Windows 上核对了版本与更新通道、发布产物脚本，以及 TRAE 额度汇总单测。TRAE 国内版额度已用本机已登录客户端对照官方菜单余额。macOS 与国际版客户端尚未完成本机人工验收。

正式版安装包与远端构建结果以本版 GitHub Actions 和 Release 实际产物为准。TRAE 切号仍只替换登录字段，本机项目和历史不按账号隔离，云端会话仍归原账号所有。Qoder 额外积分没有官方逐包到期时间，界面不会把它写成长期有效。
